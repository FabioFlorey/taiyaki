## Maintainer notes

The standalone website's updated source is kept in `site/`, with CSS,
JavaScript, fonts, and images under `site/assets/`. The former website files
in `docs/` remain temporarily for compatibility with any Pages deployment
still configured to publish from that directory.

Run `bash scripts/check-site.sh` from the repository root to validate the
new static site without starting or deploying anything.
